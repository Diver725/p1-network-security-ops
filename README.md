## 面试高频题（附答题要点）
1. 防火墙默认策略怎么设？为什么 WAN 阻断、LAN 放行？
   要点：默认拒绝 + 最小放行；WAN 是对外不可信区域，禁止主动入站；LAN 为可信内网，放行出站并做 NAT。
2. IDS 和 IPS 的区别？Suricata 如何检测攻击？
   要点：IDS 只告警不阻断，IPS 可拦截；Suricata 基于规则特征（ET Open）对流量做内容级匹配。
3. WAF 和防火墙的区别？SQL 注入怎么防？
   要点：防火墙看 IP/端口，WAF 看 HTTP 内容；防护包括参数化查询/输入校验（根本）+ WAF 拦截（补偿）。
4. 等保 2.0 三级技术部分包含哪些层面？怎么做整改？
   要点：通信网络、区域边界、计算环境、管理中心、物理环境；流程为差距分析到整改到复测到报告。
5. 收到 SSH 暴力破解告警，你的处置流程？
   要点：确认攻击源/次数/时间窗、判断是否成功、检查痕迹（auth.log/last/auditd）、封禁源 IP、恢复与报告。
6. fail2ban 原理？ignoreself 是什么？
   要点：读日志、按阈值统计失败次数、调用防火墙封禁；ignoreself 会忽略本机来源，测试需从其他主机发起。
7. Wazuh 与 auditd 的区别？
   要点：auditd 单机审计记录；Wazuh 集中采集多机日志、规则分析、告警与可视化。
8. 如何排查"内网机器 DNS 解析失败"？
   要点：分层定位（本机到网关 DNS 到上游 DNS），用 nslookup 指定服务器逐层验证，区分 SERVFAIL 与网络不可达。
