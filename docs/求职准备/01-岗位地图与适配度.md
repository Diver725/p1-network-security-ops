# 岗位地图与适配度（网安非开发方向）

背景：东南大学网络空间安全专业本科，2026 届秋招；不喜欢开发；性格偏内向、意义驱动；项目经验以本套安全运维实验为主。

| 方向 | 主要工作 | 适配度 | 需要的准备 | 备注 |
|---|---|---|---|---|
| 安全运营 SOC / 蓝队值守 | 监控 SIEM、告警研判、应急响应、护网值守 | 高 | Wazuh 规则、告警分析、事件报告（本项目已有） | 需求量大，护网期间值班 |
| 安全运维（设备） | 防火墙/IDS/WAF/堡垒机/日志平台运维 | 高 | 设备配置、规则、排错（本项目已有） | 央国企/金融/政企对口 |
| 等保测评 / 安全合规 | 对照标准测评、写报告、整改指导 | 高 | 等保 2.0 条文、报告写作；NISP/CISP 加分 | 偏文档型，适合内向 |
| 应急响应工程师 | 事件溯源、取证、处置 | 中高 | 日志分析、取证、报告 | 与 SOC 接近 |
| 安服工程师（渗透/评估） | 渗透测试、漏洞评估 | 中 | 渗透工具链（Kali）、漏洞原理 | 需持续学技术，偏攻 |
| 安全产品交付/售前 | 部署产品、方案讲解 | 中低 | 沟通表达、产品知识 | 现阶段沟通压力较大 |
| 央国企/考公信息技术岗 | 信息中心安全运维、信息化 | 中高 | 笔试（行测/申论/专业）、校招流程 | 东大牌子有优势 |
| 安全研发/逆向/漏洞挖掘 | 工具与引擎开发、漏洞研究 | 低 | 编程与逆向能力 | 与个人偏好不符 |

## 结论与建议
1. 主攻两条线：安全运营/运维 + 等保测评/合规；央国企校招与考公作为平行备选。
2. 优势：985 院校背景 + 成体系的实战项目（边界/主机/日志/合规/应急全覆盖）。
3. 短板：无一实习、无竞赛；建议用本项目作品集 + 证书（NISP 二级）=补上，同时争取护网/实习机会。
