## 一、Linux 运维（最高频）

### ⭐ 常用命令分类（按"要干什么"记）

| 目的 | 命令 |
|---|---|
| 看进程 | `ps aux`、`top`/`htop` |
| 看端口 | `ss -tlnp`（推荐）、`netstat -tlnp` |
| 看服务 | `systemctl status/start/stop/restart/enable/disable 服务名` |
| 看日志 | `journalctl -u 服务 -n 50`、`tail -f /var/log/xxx.log`、`grep 关键词 文件` |
| 看磁盘 | `df -h`、`du -sh 目录`、`lsblk` |
| 看内存 | `free -h` |
| 看网络 | `ip a`、`ip route`、`ping`、`curl`、`ss` |
| 权限 | `ls -l`、`chmod`、`chown`、`umask` |
| 用户 | `useradd`、`passwd`、`id`、`sudo` |

### 🔧 常见故障排查（面试常给场景）

**① 磁盘满了**
1. `df -h` 找出哪个分区满
2. `du -sh /*` 或 `du -sh /var/*` 逐层定位大目录
3. 常见元凶：日志（/var/log）、缓存、索引数据
4. 处理：清理/轮转日志、扩容（LVM 可在线扩）

**② CPU 100%**
1. `top` 找占用最高的进程
2. `ps -ef | grep 进程名` 看是谁
3. 结合日志判断是正常业务高峰还是异常（挖矿/死循环）

**③ 内存不足**
1. `free -h` 看 used/available、swap
2. `ps aux --sort=-%mem | head` 找大户
3. 处理：优化配置、限流、加内存、处理内存泄漏

**④ 服务起不来**
1. `systemctl status 服务` 看状态和最近日志
2. `journalctl -u 服务 -n 50` 看详细报错
3. 检查：配置文件语法、端口占用、依赖服务、权限、磁盘满

**⑤ 网络不通**
分层查：网卡/IP → 网关 ping → DNS（nslookup）→ 目标端口（nc/curl）→ 防火墙规则

### 必背概念
- **LVM**：PV（物理卷）→ VG（卷组）→ LV（逻辑卷）→ 文件系统；可在线扩容 ⭐
- **权限**：rwx 对应读/写/执行；`755`=属主读写执行、其他读执行；**SUID** 让程序以属主身份运行（危险，需定期盘点）
- **软链接 vs 硬链接**：软链接可跨分区、可指向目录；硬链接指向同一 inode、不能跨分区
- **开机流程**：BIOS/UEFI → GRUB → 内核 → initramfs → systemd → 目标 target
- **crontab 格式**：分 时 日 月 周（`0 2 * * *` = 每天 2 点）
- **SSH 免密原理**：客户端生成密钥对，公钥放目标机 `~/.ssh/authorized_keys`，私钥保留本地

## 二、网络基础（必考）

### ⭐ OSI 七层 / TCP-IP 四层

| OSI 七层 | TCP/IP 四层 | 典型协议/设备 |
|---|---|---|
| 应用层/表示层/会话层 | 应用层 | HTTP、DNS、SSH、FTP |
| 传输层 | 传输层 | **TCP、UDP** |
| 网络层 | 网络层 | **IP、ICMP**、路由器 |
| 数据链路层/物理层 | 网络接口层 | 以太网、交换机、网卡 |

### ⭐ TCP 三次握手 / 四次挥手
- 三次握手：SYN → SYN+ACK → ACK（**确认双方收发能力都正常**）
- 四次挥手：FIN → ACK → FIN → ACK（因为 TCP 是全双工，两个方向要分别关闭）

### ⭐ TCP vs UDP
| | TCP | UDP |
|---|---|---|
| 连接 | 面向连接 | 无连接 |
| 可靠性 | 可靠（重传、有序） | 不可靠、快 |
| 场景 | HTTP、SSH、数据库 | DNS、视频、游戏 |

### ⭐ 常见端口
22=SSH、80=HTTP、443=HTTPS、53=DNS、25=SMTP、110=POP3、143=IMAP、3306=MySQL、6379=Redis、3389=RDP、1514=Wazuh Agent、514=syslog、9443=雷池控制台

### 基础概念
- **子网掩码**：划分子网；`/24`=255.255.255.0（可用 254 个地址）
- **网关**：出网的默认出口
- **DHCP**：自动分配 IP（租约制）
- **DNS**：域名转 IP（递归 vs 迭代查询；A/CNAME/MX 记录）
- **NAT**：内网地址翻译成出口地址（内网多台共用公网 IP）
- **HTTP vs HTTPS**：HTTPS = HTTP + TLS 加密，需证书

### 排错命令
`ping`（连通）、`traceroute`（路径）、`nslookup/dig`（DNS）、`nc -vz`（端口）、`tcpdump`（抓包）、`curl -I`（看 HTTP 头）

## 三、安全基础

### ⭐ 常见攻击与防御

| 攻击 | 原理 | 防御 |
|---|---|---|
| **SQL 注入** | 输入被拼进 SQL，改变查询逻辑（`' or '1'='1`） | 参数化查询（根本）+ WAF（补偿）+ 最小权限 |
| **XSS** | 网页注入恶意脚本，窃取 Cookie | 输入输出过滤、CSP |
| **CSRF** | 诱导用户带着登录态发请求 | Token 校验、SameSite Cookie |
| **文件上传** | 上传 webshell 拿服务器权限 | 类型/后缀白名单、隔离存储、权限最小化 |
| **暴力破解** | 反复试密码 | 强口令、密钥认证、**fail2ban 封禁**、限制来源 |
| **DDoS** | 海量流量耗尽资源 | 流量清洗、CDN、限速 |
| **钓鱼** | 骗人点链接/附件 | 邮件网关、安全意识培训 |
| **挖矿木马** | 入侵后跑挖矿程序 | 监控异常进程/外联、打补丁 |

### 加密与认证
- **对称加密**（AES）：同一把钥匙加解密，快
- **非对称加密**（RSA）：公钥加密、私钥解密（或反之签名），慢
- **哈希**（SHA256/MD5）：单向摘要，用于校验/存密码（存密码要加盐）
- **数字签名**：用私钥签、公钥验，证明来源和完整性
- **HTTPS 握手**：证书验证 + 协商会话密钥 + 加密通信

### 日志与审计
- `auditd`：Linux 审计（谁改了关键文件）
- `syslog`：系统日志转发（UDP 514）
- **SIEM**：多机日志集中 + 规则分析 + 告警

## 四、安全设备与平台 ⭐

| 设备 | 作用 | 关键点 |
|---|---|---|
| **防火墙** | 按 IP/端口放行或阻断 | 默认拒绝 + 最小放行；WAN 阻断入站、LAN 放行出站；NAT |
| **IDS** | 入侵**检测**，只告警不阻断 | 旁路部署 |
| **IPS** | 入侵**防御**，可阻断 | 串联/内联部署 |
| **WAF** | 看 **HTTP 内容**，防 SQLi/XSS 等 | 与防火墙区别：防火墙看 IP/端口，WAF 看内容 |
| **堡垒机** | 运维统一入口 + 审计 | 四要素：身份认证、权限控制、操作审计、资产管理 |
| **SIEM** | 日志集中 + 关联分析 + 告警 | Wazuh、奇安信、深信服 |
| **漏洞扫描器** | 发现已知漏洞 | GVM/Nessus；扫前要授权 |
| **基线核查工具** | 检查配置是否合规 | Lynis、CIS Benchmark |

**国产化对应（面试可能问）**：华为/深信服/天融信（防火墙）、绿盟/启明星辰（IDS）、安恒/绿盟（WAF）、齐治/帕拉迪（堡垒机）、奇安信/深信服（SIEM/态势感知）

## 五、等保与合规 ⭐（央国企必问）

### 等保 2.0 基础
- 全称：**网络安全等级保护**；分 **五级**（一级最低，五级最高）
- 常见：**二级**（一般企业系统）、**三级**（重要系统，央国企主流）
- 五个规定动作：**定级 → 备案 → 建设整改 → 等级测评 → 监督检查**

### ⭐ 三级技术要求五层（必背）
1. **安全物理环境**（机房、门禁、防火）
2. **安全通信网络**（传输加密、可信验证）
3. **安全区域边界**（边界防护、访问控制、**入侵防范**、安全审计）
4. **安全计算环境**（身份鉴别、访问控制、安全审计、入侵防范、恶意代码防范）
5. **安全管理中心**（**集中管控、集中审计**、时间同步、三权分立）

### 护网行动（HW）
- **红队**：攻击方（模拟真实攻击）
- **蓝队**：防守方（监测、研判、处置、上报）← 运维岗主要参与
- **紫队**：统筹协调
- **蓝队值守流程**：告警监测 → 初步研判（真/假、是否成功）→ 处置（封禁/隔离）→ 上报 → 复盘

### 电力行业专项（如国家电网）
- **十六字方针**：**安全分区、网络专用、横向隔离、纵向认证**
- 生产控制大区与管理信息大区严格隔离；横向单向隔离装置

## 六、应急响应 ⭐

### 标准流程（六步）
**准备 → 检测/发现 → 遏制 → 根除 → 恢复 → 跟踪总结**
（面试口述版：发现 → 研判 → 处置 → 恢复 → 报告）

### 常见事件处置要点
| 事件 | 关键动作 |
|---|---|
| SSH 暴力破解 | 确认来源/次数、查是否得手、封禁 IP、检查痕迹、加固 |
| Webshell | 定位文件、断网隔离、取证（保留现场）、清除后门、修补漏洞 |
| 挖矿木马 | 找异常进程/外联、断网、清除、查入侵入口、加固 |
| 勒索病毒 | **立即断网**、保留现场、评估备份、恢复、溯源 |
| 数据泄露 | 定位数据源、封堵出口、评估影响、上报 |

### 取证与报告
- 保留现场：不轻易删文件/重启，先做快照/镜像
- 采集证据：日志、进程、网络连接、文件时间线
- **IOC**：攻击源 IP、域名、文件哈希、恶意特征
- 报告结构：事件概述 / 时间线 / 攻击路径 / IOC / 影响评估 / 处置动作 / 复盘改进

## 七、自动化与脚本

### ⭐ Ansible（P2 核心）
- 定位：**无代理（agentless）** 自动化运维工具，通过 **SSH** 管理被管机
- 核心概念：**inventory（主机清单）**、**module（模块）**、**playbook（YAML 剧本）**
- **幂等性**：同一剧本重复执行结果一致，不会重复乱改 ⭐
- 常用模块：`ping`、`apt`、`copy`、`service`、`user`、`lineinfile`、`shell`
- 参数记忆：`-i`（清单）、`-m`（模块）、`-a`（参数）、`-b`（提权）、`-K`（become 密码）

### Shell 与文本处理
- `grep`：筛选（`-i` 忽略大小写、`-v` 反选、`-E` 多条件、`-n` 行号）
- `awk`：按列处理文本；`sed`：流式替换
- `find`：按名字/权限/时间找文件（如 `find / -perm -4000` 找 SUID）
- 管道 `|`：把前一个命令输出交给后一个处理

## 八、虚拟化与容器

| 概念 | 要点 |
|---|---|
| 虚拟机 | 完整操作系统，资源隔离强，重 |
| **快照** | 保存某一时刻状态，可回滚；**不是备份**（同在宿主磁盘） |
| **克隆** | 完整克隆独立；链接克隆依赖母盘；克隆后要改主机名/MAC/SSH 主机密钥 |
| **Docker** | 共享宿主内核，轻量；镜像/容器/仓库；与虚拟机区别=共享内核 |
| NAT/桥接/host-only | NAT=可上网但外部难访问；桥接=像真机接入局域网；host-only=主机与虚拟机互通、不通外网 |

## 九、面试答题话术

### ⭐ 自我介绍（2 分钟模板）
1. 学校专业 + 求职方向（10 秒）
2. 掌握的技能栈（Linux、网络安全设备、等保、自动化）（30 秒）
3. **项目经历**（用下面 STAR 讲一个最熟的，40 秒）
4. 为什么选这个岗位/公司 + 期望（20 秒）

### ⭐ 项目讲解模板（STAR）
- **背景 S**：要解决什么问题（例：企业内网需要安全分区和日志审计）
- **任务 T**：我负责什么（例：独立搭建防火墙分区与日志平台）
- **行动 A**：具体做了什么（3 个关键动作）
- **结果 R**：量化结果（例：SSH 爆破 8 次即被封禁；等保 3 项整改复测通过）

### 用我们的真实案例回答"遇到的最大困难"（很有说服力）
1. **DNS 故障排查**：内网域名全部解析失败 → 用 nslookup 分层验证（本机→网关→公网）→ 定位到网关 DNS 服务 → 改 DHCP 下发公网 DNS 恢复
2. **磁盘写满导致安装失败**：Wazuh 安装中断 → `df -h` 定位 → 扩容磁盘（LVM 四步）→ 修复受损的包管理器（dpkg 半装状态）→ 重装成功
3. **fail2ban 不生效**：状态一直 0 → 查日志发现 ignoreself 忽略本机来源 → 改为从另一台机器测试 → 成功封禁
4. **克隆机 MAC/主机密钥重复**：多台机器通信异常/SSH 警告 → 重新生成 MAC 与主机密钥解决

### 反问环节（体现你在意岗位）
- 团队日常的安全运营工作有哪些（监控/应急/合规比例）？
- 新人入职后主要负责哪部分工作？
- 有没有护网/等保测评的参与机会？

## 十、高频速答题（20 题，自己先答再看要点）

1. **查看端口占用的命令？** `ss -tlnp`（旧：netstat -tlnp）
2. **磁盘满了怎么排查？** `df -h` 找分区 → `du -sh` 逐层定位 → 清日志/扩容
3. **CPU 100% 怎么查？** `top` 找进程 → `ps` 确认 → 看日志判断正常/异常
4. **服务起不来怎么查？** `systemctl status` + `journalctl -u` 看报错 → 检查配置/端口/权限/磁盘
5. **TCP 三次握手？** SYN → SYN+ACK → ACK，确认双方收发能力
6. **TCP 和 UDP 区别？** 连接/可靠/有序 vs 无连接/快/不可靠
7. **HTTP 和 HTTPS 区别？** HTTPS 加了 TLS 加密与证书验证
8. **常见端口？** 22/80/443/53/3306/6379/3389/1514/514
9. **NAT 是什么？** 内网地址翻译成出口地址，多台共享一个公网 IP
10. **防火墙和 WAF 区别？** 防火墙看 IP/端口，WAF 看 HTTP 内容
11. **IDS 和 IPS 区别？** 检测告警 vs 检测并阻断
12. **SQL 注入原理与防御？** 输入拼进 SQL 改变逻辑；参数化查询 + WAF
13. **等保三级技术五层？** 物理环境/通信网络/区域边界/计算环境/管理中心
14. **等保流程？** 定级→备案→建设整改→测评→监督检查
15. **护网蓝队做什么？** 监测告警、研判、处置、上报、复盘
16. **应急响应流程？** 准备→检测→遏制→根除→恢复→跟踪总结
17. **怎么判断主机被入侵？** 异常进程/外联、异常账号、文件篡改、日志异常、CPU/流量异常
18. **Ansible 原理与幂等性？** 无代理走 SSH；幂等=重复执行结果一致
19. **堡垒机作用？** 统一运维入口，身份认证+权限控制+操作审计+资产管理
20. **SIEM 是什么？** 多源日志集中存储、关联分析、告警与可视化
