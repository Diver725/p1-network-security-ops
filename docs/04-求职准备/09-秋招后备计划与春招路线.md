# 秋招后备计划与春招路线

> 适用情况：2027 届，当前秋招结果不理想，计划通过实习、证书、竞赛和项目补强，继续准备春招与毕业后就业。

## 一、总体策略

不要等到秋招完全结束再行动。

建议同时推进：

```text
秋招补录
→ 寒假实习
→ 证书和竞赛
→ 项目补强
→ 春招正式投递
```

两条主线：

```text
主线 A：系统运维 / Linux 运维 / 安全运维 / SOC
主线 B：安全服务 / 安全产品实施 / 应急响应
```

如果后续想转渗透攻防，需要额外补：

```text
Web 安全
Python / Shell
CTF
Burp Suite
漏洞原理
渗透测试流程
```

## 二、优先级排序

### 第一优先级：实习

对没有实习经历的候选人，实习是最有效的补强。

目标实习方向：

```text
安全运维实习生
SOC 分析师实习生
安全服务工程师实习生
系统运维实习生
Linux 运维实习生
网络运维实习生
安全产品实施实习生
渗透测试实习生（有 Web 和 CTF 基础后）
```

优先公司类型：

```text
安全厂商
政企安全服务商
互联网公司安全部门
银行/证券/保险信息科技部门
运营商/云厂商
大型企业信息中心
```

实习目标：

```text
获得真实生产环境经验
接触安全设备或 SIEM
积累可写入简历的成果
争取转正或获得春招优势
```

### 第二优先级：证书

推荐顺序：

```text
1. NISP 二级
2. 软考网络工程师 / 信息安全工程师
3. 华为 HCIA-Security / HCIP-Security
4. 深信服、奇安信等厂商认证
5. 云厂商基础认证
6. CISP（有工作经验后考虑）
```

说明：

- NISP 二级适合学生，央国企、等保和安全运维方向认可度较好。
- 软考适合国企、事业单位、政企和信息化岗位。
- 厂商认证更适合安全设备运维和安全服务岗位。
- 不建议只追求证书数量，要保证能解释和动手操作。

### 第三优先级：比赛

适合持续参与：

```text
SUSCTF
强网杯
全国大学生信息安全竞赛
各类校内 CTF
企业或社区 CTF
护网行动（如有机会）
```

对运维/安全运营岗位：

```text
比赛是加分项，不是唯一核心
优先补 Linux、网络、日志、应急和真实项目
```

对渗透/攻防方向：

```text
CTF 权重更高
需要持续做 Web、Misc、Crypto、Reverse、Pwn
```

### 第四优先级：项目补强

在当前三个项目基础上，可以继续做：

```text
Wazuh Dashboard 告警视图
ELK / OpenSearch 日志分析
Suricata 规则调优
WAF 规则和拦截分析
GVM 自动扫描流程
Ansible 自动化巡检
Python/Bash 日志分析脚本
云主机安全基线
容器和 Kubernetes 安全入门
```

推荐增加一个“可展示的小工具”：

```text
日志分析和 IOC 提取脚本
SSH 暴破分析脚本
Apache 日志目录扫描检测脚本
FIM 可疑文件哈希查询脚本
```

## 四、秋招不理想时的具体行动

### 1. 不要停止投递

即使到 11 月、12 月，也继续投：

```text
秋招补录
寒假实习
春招提前批
企业官网补录
内推岗位
```

### 2. 找一段能写进简历的实习

优先选择：

```text
有真实 Linux/网络环境
有安全设备或 SIEM
有工单、巡检、应急、报告输出
有导师带
有机会转正
```

避免：

```text
只做简单客服
只做重复录入
完全接触不到技术
长期无成长空间
```

### 3. 用实习补充简历

实习结束后应至少形成：

```text
一段实习职责描述
1–2 个真实排错或处置案例
一份巡检/应急/分析报告
量化结果
```

### 4. 继续运营 GitHub

至少保持：

```text
P1/P2/P3 三个主项目
一个安全脚本或日志分析工具
一个 CTF Writeup 或学习记录
README 清楚说明背景、技术栈和结果
```
