## 二、项目一：企业网络安全建设与等保整改（本仓库）
- 项目背景：在隔离虚拟环境中模拟企业网络，构建"边界防护、主机加固、日志审计、Web 防护、合规整改、应急响应"完整体系
- 主要工作：
  1. 基于 pfSense 完成内外网分区与防火墙策略，部署 Suricata 入侵检测、雷池 WAF 与 Wazuh SIEM
  2. 完成业务主机安全加固（SSH、口令复杂度、服务最小化、SUID 盘点、auditd、fail2ban）
  3. 按等保 2.0 三级要求完成差距分析与整改，输出整改报告并复测
  4. 组织两起安全事件演练并输出标准化事件报告（SSH 暴力破解、SQL 注入）
- 成果/量化：覆盖 5 台虚拟机与 3 个网段；8 次 SSH 爆破尝试被 fail2ban 自动封禁；SQL 注入请求被 WAF 拦截（403）；完成 3 项等保整改并复测通过
- 技术栈：pfSense、Suricata、雷池 WAF、Wazuh、nginx、auditd、fail2ban、Kali、VirtualBox、Git

## 五、可讲"真实坑"案例（面试加分）
- pfSense 安装下载失败：识别为虚拟机不走系统代理导致，用代理虚拟网卡模式解决
- 内网 DNS SERVFAIL：分层排查（本机、网关、上游），定位 pfSense DNS 服务问题并改用公网 DNS + 后续整改
- Wazuh 安装失败：磁盘写满导致 dpkg 状态损坏，扩容并按"空脚本替换 prerm/postrm + force 清除"修复后重装
- fail2ban 不生效：定位为 ignoreself 规则忽略本机来源，改为从其他主机测试
