## 项目经历

### 项目一：企业网络安全建设与等保整改

- 基于 pfSense 完成内外网和 DMZ 网络分区，部署 Suricata IDS、雷池 WAF 与 Wazuh SIEM，覆盖 5 台虚拟机和 3 个网段。
- 完成业务主机安全加固，包括 SSH、口令复杂度、无用服务清理、SUID 盘点和 auditd 审计，并通过 fail2ban 实现 SSH 暴破自动封禁。
- 按等保 2.0 三级要求完成差距分析、整改和复测，输出整改报告。
- 完成 SSH 暴破和 SQL 注入安全事件演练，输出包含时间线、IOC、处置和验证结果的事件报告。

技术栈：pfSense、Suricata、雷池 WAF、Wazuh、nginx、auditd、fail2ban、Kali、VirtualBox、Git

### 项目二：企业漏洞管理与安全基线自动化加固

- 使用 nmap 和 Ansible 建立 4 台 Ubuntu 主机的资产清单和统一管理链路。
- 使用 Lynis 和 GVM 完成安全基线与漏洞扫描，建立加固前风险基线。
- 编写 Ansible 加固剧本，实施 SSH、UFW、sysctl、PAM、fail2ban 和 auditd 等配置。
- 完成加固前后复测：Lynis hardening index 从 57 提升到 75，warnings 从 2 降到 0，GVM Low 风险从 9 降到 0，并记录 CPU 微码类残余风险。

技术栈：Ubuntu、Ansible、GVM、Lynis、nmap、UFW、PAM、sysctl、Git

### 项目三：SOC 安全运营与护网应急响应

- 基于 Wazuh 4.14 搭建单节点 SOC 实验环境，接入 Ubuntu Web 靶机 Agent，采集 SSH、Apache、系统日志和 FIM 事件。
- 编写三条自定义规则，分别覆盖 SQL 注入内容特征、目录扫描频率关联和 Web 上传目录文件新增。
- 完成 SSH 暴破、SQL 注入、目录扫描和可疑 Web 文件四类场景的检测、研判和应急处置。
- 输出四份安全事件报告，包含原始日志、Wazuh 告警、IOC、影响评估、处置动作、验证结果和改进建议。

技术栈：Wazuh、Ubuntu、Apache、DVWA、MariaDB、UFW、Hydra、Gobuster、curl、Git
