### R1（2026-09-08）给 p1-web 安装 Wazuh Agent
- 做了什么：用 Wazuh Deploy 向导安装 wazuh-agent（DEB），WAZUH_MANAGER=192.168.20.101，enable+start
- 验证：Endpoints 显示 p1-web Active；Discover 搜到 p1-web 的 sudo/PAM 日志（agent.ip=192.168.20.102）
- 截图：screenshots/2026-09-08-Wazuh-Web服务器Agent.png（待补确认）
- 说明：Agent IP 显示 any 不影响数据上报（Active + 日志已验证）

### R2（2026-09-10）SSH 增强：会话超时 + fail2ban
- 做了什么：
  - SSH 会话超时：ClientAliveInterval 300 + ClientAliveCountMax 2（空闲约 10 分钟断开）
  - 安装 fail2ban，配置 jail.local：bantime=600、findtime=600、maxretry=5、logpath=/var/log/auth.log
- 验证：从 p1-web（192.168.20.102）对 p1-lan-client 发起 6 次错误密码登录 → fail2ban 记录 Total failed: 6、Currently banned: 1、封禁 IP 192.168.20.102
- 踩坑记录：fail2ban 的 ignoreself 规则会忽略本机(127.0.0.1)来源的失败，必须从另一台机器测试
- 截图：screenshots/2026-09-09-fail2ban拦截.png
- 等保对应：安全计算环境—身份鉴别/入侵防范

### R3（2026-09-10）时间同步核查与整改
- 发现问题：客户端/Web 的 NTP 服务在运行，但 System clock synchronized 为 no（默认 ntp.ubuntu.com 国内不可达）；pfSense 仅显示 pool 占位、stratum 16、reach 0
- 整改动作：
  - 客户端与 Web：新增 /etc/systemd/timesyncd.conf.d/99-lab.conf，使用 ntp.aliyun.com / ntp1.aliyun.com / ntp.tencent.com / ntp.ntsc.ac.cn
  - pfSense：Services→NTP 改用 ntp.aliyun.com / ntp1.aliyun.com / ntp.tencent.com
- 复测结果：两台虚拟机 timedatectl 显示 System clock synchronized: yes、NTP service active；pfSense Status→NTP 出现 Active Peer 203.107.6.88（stratum 3、reach 7、offset +0.438ms）
- 截图：screenshots/2026-09-10-NTP同步.png（待补）
- 等保对应：安全管理中心—时间同步

### R4（2026-09-11）防火墙日志接入 Wazuh（集中审计）
- 差距：防火墙（边界）日志未纳入集中审计，不满足安全区域边界-安全审计与安全管理中心-集中审计要求
- 整改动作：
  - Wazuh 侧：新增独立 remote 块启用 syslog 接收（UDP 514，allowed-ips 192.168.20.0/24）；开启 logall/logall_json；Filebeat 启用 archives 模块
  - pfSense 侧：Status-System Logs-Settings 配置远程 syslog 至 192.168.20.101:514，发送 Firewall Events 与 System Events；并在 LAN 规则上启用包日志
- 复测结果：Wazuh 收到 pfSense 日志（archives.json 中 location=192.168.20.1），含 sshguard、syslogd 与 filterlog 记录（示例：192.168.20.100 到 223.5.5.5 的 ICMP/TCP）；控制台 wazuh-archives-* 数据视图可检索
- 踩坑记录：① 一个 remote 块只能放一种 connection，syslog 必须独立成块；② Filebeat 的 archives 配置需正确缩进（enabled 比 archives 多缩进一层）
- 截图：screenshots/2026-09-11-防火墙日志接入Wazuh.png
- 等保对应：安全区域边界—安全审计；安全管理中心—集中审计
