## 场景一：SSH 暴力破解

- 攻击：Kali 对 p1-lan-client（192.168.20.100）SSH 端口进行错误密码尝试（hydra 或循环 sshpass）
- 检测：Wazuh 收到客户端认证失败日志 → 触发告警（sshd: authentication failed，level 5）；fail2ban 达到阈值自动封禁攻击源 IP
- 处置流程：查看告警 → 确认攻击源（IOC：攻击 IP、失败次数、时间窗口）→ 封禁 IP（fail2ban + 可选 pfSense 规则）→ 检查主机痕迹（auth.log、last、auditd）→ 解除封禁/恢复服务 → 输出事件报告
- 需要截图：Wazuh 告警、fail2ban 封禁状态、客户端日志痕迹、研判结论

## 场景二：Web SQL 注入

- 攻击：对 WAF 地址（192.168.20.103）发起 SQL 注入请求（?id=1' or '1'='1）
- 检测：雷池 WAF 拦截（HTTP 403），攻击事件记录"已拦截 / SQL 注入"，来源 IP 为攻击方
- 处置流程：查看攻击事件 → 提取 IOC（攻击 IP、payload、时间）→ 在 WAF 加入黑名单 → 验证正常访问不受影响 → 输出事件报告
- 需要截图：WAF 拦截页、攻击事件详情、黑名单配置
