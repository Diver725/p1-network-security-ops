# P1 第 2 周加固记录：业务主机安全配置（等保·安全计算环境）

日期：2026-09-06　对象：p1-lan-client（Ubuntu 24.04，192.168.20.100）

## 加固前后对照

| 检查项 | 加固前（基线） | 加固后 | 说明 |
|---|---|---|---|
| SSH root 登录 | 默认（未显式禁止） | PermitRootLogin no | 禁止 root 直接 SSH |
| SSH 密码尝试次数 | 默认（不限） | MaxAuthTries 3 | 防暴力破解 |
| SSH 登录超时 | 默认 | LoginGraceTime 30 | 防慢速爆破挂连接 |
| SSH 允许用户 | 默认（所有用户） | AllowUsers lab | 最小化可登录用户 |
| 密码强度 | 无要求 | minlen=12，强制数字/大写/小写 | pwquality 规则 |
| 无用服务 | ModemManager、multipathd 在跑 | 已停用并禁止自启 | 减少攻击面 |
| SUID 文件 | 盘点出 13 个系统标准文件 | 无新增可疑项 | find / -perm -4000 定期核对 |
| 审计日志 | 无 | auditd 启用 + 4 条盯防规则 | 记录关键文件改动 |
| 开放端口 | 仅 22（SSH） | 仅 22（SSH） | 无新增暴露 |

## 关键操作记录

1. SSH 加固：备份 sshd_config → 新增 /etc/ssh/sshd_config.d/99-hardening.conf（PermitRootLogin no / MaxAuthTries 3 / LoginGraceTime 30 / AllowUsers lab）→ sshd -t 语法检查 → restart ssh → 新窗口验证可登录。
2. 口令策略：安装 libpam-pwquality → 确认 pam_pwquality.so 已接入 → 在 /etc/security/pwquality.conf 追加 minlen=12、dcredit=-1、ucredit=-1、lcredit=-1。
3. 服务最小化：systemctl disable --now ModemManager.service multipathd.service。
4. SUID 盘点：find / -perm -4000 -type f 2>/dev/null，13 个均为系统标准文件，存档为标准清单。
5. 审计：安装 auditd → 启停自启 → auditctl -w 盯防 /etc/passwd、/etc/shadow、/etc/ssh/sshd_config、/etc/sudoers → ausearch 验证有记录。

## 复测确认（加固后）
- sudo sshd -T 显示实际生效：maxauthtries 3 / permitrootlogin no / allowusers lab
- ss -tlnp：仅 22 端口对外，无新增暴露
- auditd 已 enabled（开机自启）
- 新开 SSH 窗口可正常登录（未把自己锁外面）

## 学习点
- 改配置前先备份；改完先语法测试（sshd -t），再另开连接验证，最后才关旧连接
- stop 只管现在，disable 管以后开机；两者配合用 disable --now
- SUID 清单要定期对比，多出来的文件要警惕
- auditd：auditctl 加规则、ausearch 查记录，第 5 周查入侵痕迹会用到
