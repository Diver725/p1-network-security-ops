# P1 项目总结：企业网络安全建设与等保整改

## 一、项目目标
在隔离虚拟环境中搭建一套小型企业网络，完成边界防护、主机加固、日志审计、Web 防护、合规整改与安全事件演练，形成可展示、可复现的安全运维作品集。

## 二、环境与技术栈
- 虚拟化：VirtualBox（host-only 内网 192.168.20.0/24；NAT 网络 p1-wan 模拟外网）
- 边界：pfSense CE（防火墙、NAT、DHCP）+ Suricata（IDS/IPS）
- 主机：Ubuntu Server 24.04（客户端、Web、Wazuh、WAF）
- 应用与安全：nginx、雷池 SafeLine WAF、Wazuh SIEM、auditd、fail2ban
- 攻击机：Kali Linux（模拟外网攻击者）

## 三、各周成果
| 阶段 | 成果 | 关键验证 |
|---|---|---|
| 第 1 周 | 网络分区、pfSense 部署、Suricata 启用 | 内网到防火墙到外网链路打通；防火墙默认策略生效 |
| 第 2 周 | 主机安全加固（SSH/口令/服务/SUID/审计） | 加固前后对照与复测，未锁死 SSH |
| 第 3 周 A | Wazuh 部署、Agent 接入 | 日志上传验证；SSH 爆破触发 level 5 告警 |
| 第 3 周 B | Web 服务器 + 雷池 WAF | 正常访问 200；SQL 注入被拦截 403 |
| 第 4 周 | Kali 攻击机、等保差距分析与整改 | R1-R3 整改完成并复测（集中审计/身份鉴别/时间同步） |
| 第 5 周 | 安全事件演练与报告 | SSH 爆破（fail2ban 封禁 + Wazuh 告警）；SQL 注入（WAF 拦截 + 黑名单处置） |
