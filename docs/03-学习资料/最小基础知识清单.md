# 最小基础知识清单（P1 版）

> 用法：不是背，而是"知道有这个东西、遇到时能想起去哪查"。
> 每条 = 一句话解释 + 怎么验证。

## 一、网络（10 条）

| 概念 | 一句话解释 | 怎么验证 |
|---|---|---|
| IP 地址 | 设备在网络里的门牌号 | ip a |
| 子网掩码 /24 | 划分网段范围，255.255.255.0 简写 /24 | ip a 里的 /24 |
| 网关 | 出网的默认大门 | ip route（default via） |
| DHCP | 自动分配 IP 的服务 | ip a 里地址是否 dynamic |
| DNS | 域名转 IP 的电话簿 | nslookup 域名 |
| NAT | 内网地址翻译成出口地址 | 内网机器 ping 公网通即说明 NAT 正常 |
| 路由 | 数据包往哪走的规则 | ip route |
| 端口 | 服务的"门牌号"（如 22/80/443） | ss -tlnp |
| 私网 vs 公网 | 10.x/172.16-31.x/192.168.x 只在局域网有效 | 看地址段 |
| 代理 / TUN | 虚拟机默认不走系统代理，需开虚拟网卡模式 | 下载失败时联想到它 |

## 二、Linux 系统（10 条）

| 概念 | 一句话解释 | 怎么验证 |
|---|---|---|
| 文件与权限 | 属主/属组/读写执行 | ls -l |
| 用户与 sudo | 普通用户临时用管理员权限 | id、sudo -l |
| 服务管理 | 用 systemd 启停/查看服务 | systemctl status/enable/restart |
| 日志 | 系统与服务日志统一查看 | journalctl -u 服务、tail -n 50 |
| 进程与端口 | 谁在跑、占了什么端口 | ps aux、ss -tlnp |
| 软件包 | 安装/卸载/更新软件 | apt update/install |
| 网络配置 | Ubuntu 用 netplan 配 IP | ip a、netplan apply |
| 防火墙（主机） | 主机自带防火墙（ufw/nftables） | ufw status |
| 时间同步 | 系统时间需与 NTP 对齐 | timedatectl |
| 磁盘与分区 | 容量、分区、LVM 扩容 | df -h、lsblk |

## 三、安全（10 条）

| 概念 | 一句话解释 | 怎么验证 / 在哪看 |
|---|---|---|
| 防火墙策略 | 默认拒绝 + 最小放行 | pfSense Firewall Rules |
| IDS / IPS | 检测（可阻断）攻击流量 | Suricata Alerts |
| WAF | 检查 HTTP 内容，防 SQL 注入等 | 雷池攻击事件 |
| SIEM | 多机日志集中 + 规则告警 | Wazuh Discover / Endpoints |
| 日志审计 | 记录谁做了什么，可追溯 | auditd / Wazuh archives |
| 基线加固 | 按安全要求收紧系统配置 | SSH 加固项、口令策略 |
| 漏洞与补丁 | 已知缺陷与修复 | 项目二（GVM/Lynis） |
| 应急响应 | 发现 → 研判 → 处置 → 恢复 → 报告 | 事件报告 01/02 |
| IOC | 失陷指标（攻击 IP、载荷、特征） | 事件报告中的 IOC 表 |
| 等保 2.0 | 国家分级保护标准（五层技术要求） | 等保差距分析与整改报告 |
