# P1 防火墙策略说明（第 1 周）

## pfSense 默认策略（安装后自带，先理解再细化）

| 方向 | 默认行为 | 含义 |
|---|---|---|
| LAN → 任意 | 放行（Allow） | 内网机器可以自由出网（上网、访问外网服务） |
| WAN → LAN | 阻断（Block） | 外网主动连内网一律拒绝（除非有端口映射规则） |
| WAN 自身 | 防锁定规则 | pfSense 自身可管理（Web 界面走 LAN 口） |

验证方法：pfSense → **Firewall（防火墙）→ Rules（规则）**，分别看 WAN 和 LAN 两个标签页。

## 查看位置（截图素材）
- Firewall → Rules → LAN 标签：应看到默认放行规则（Default allow LAN to any）
- Firewall → Rules → WAN 标签：应看到默认阻断规则（Default deny all / block）

## 后续细化计划（配合等保"安全区域边界"）
- [ ] 按最小权限原则收紧 LAN 规则（如只放行 Web/SSH 等业务端口，第 2-3 周结合业务落地）
- [ ] 演练"封禁攻击 IP"：用 pfSense 别名(Alias)+阻断规则实现（第 4-5 周事件演练用）
- [ ] 可选：DMZ 区规则（Web 服务器放 DMZ 后，放行 80/443 到 DMZ，阻断 DMZ 访问内网）
