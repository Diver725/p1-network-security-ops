## 任务卡 C（先做这张）：WAF 拦截 SQL 注入并处置

**目标**：让一个 Web 站点处于 WAF 保护之下，正常访问能通、SQL 注入被拦截，并完成"拉黑攻击源 → 验证 → 恢复"的处置闭环。

**前置环境**
- 开机：p1-pfsense、p1-web（.102）、p1-waf（.103）
- 操作机：Windows（浏览器 + PowerShell）

**验收标准（全部满足才算过）**
- [ ] 浏览器访问 WAF 地址能看到 Web 页面（正常放行）
- [ ] 发起 SQL 注入请求，返回 403 且出现 WAF 拦截页面
- [ ] 在 WAF 控制台能看到该攻击事件（类型、来源 IP、时间）
- [ ] 把攻击源 IP 加入黑名单后，正常访问也被拒绝（403）
- [ ] 移除黑名单后，访问恢复正常（200）
- [ ] 截图留档并在 `reports/` 写一份简短事件记录（可事后补）

**提示方向（只在卡住时看）**

- WAF 默认可能是"观察"模式，观察模式和拦截模式差别是什么？
- 拉黑/解封在 WAF 的哪个菜单？（黑白名单）
