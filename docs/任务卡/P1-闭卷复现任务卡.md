## 任务卡 A：fail2ban 封禁验证

**目标**：从另一台机器制造 SSH 登录失败，验证目标机 fail2ban 自动封禁来源 IP，并完成解封。

**前置环境**：p1-pfsense、p1-lan-client（.100）、p1-web（.102，作为攻击源）

**验收标准**
- [ ] 在 p1-web 上对 .100 发起多次错误密码尝试
- [ ] 在 .100 上看到封禁状态里出现 p1-web 的 IP，且失败次数统计正确
- [ ] 解封后恢复正常
- [ ] 能解释：为什么在本机（127.0.0.1）测试不会触发封禁？

**提示方向**：日志来源是什么？统计窗口/阈值参数在哪配？ignoreself 规则是什么？

**卡点记录（2026-09-13）**
- 忘了当初怎么配置加固项（怀疑是参数名=值）→ 已澄清：sshd_config 用「参数名 + 空格 + 值」；且通过 drop-in 文件 /etc/ssh/sshd_config.d/99-hardening.conf 添加，主配置不动
- 忘了语法检查（sshd -t）的作用 → 已理解：只校验语法不重启服务，防止配置写错导致 SSH 起不来、把自己锁在门外
- 能独立复述 5 步流程：备份 → 追加加固配置 → 语法检查 → 重启服务 → 另开窗口验证
- 学会用 man sshd / 参数查询选项含义；学会 grep 的两种输入来源（文件 / 管道）
**耗时**：约 20 分钟　**求助次数**：概念提问为主
