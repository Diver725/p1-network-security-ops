# P1 实验环境保存与恢复说明

> 结论：**P1 的整套环境可以完整保留**，随时回来复现任务。推荐"三层保存"：关机保存 + 快照 + 离线备份。

## 二、三层保存方案

### 第一层：关机保存（必做，成本最低）
- 在 VirtualBox 里**正常关机**（不是"暂停"；暂停仍占内存）
- 关机后**不占用主机内存**，磁盘文件保留，随时可以再开机
- 当前 P1 约占用 97GB，E 盘剩余约 347GB，足够

### 第二层：快照（推荐）
- 给关键虚拟机拍快照，命名建议 **`p1-complete`**（标记"P1 完成时的状态"）
- 建议拍：p1-pfsense、p1-lan-client、p1-wazuh、p1-web、p1-waf
- 用途：以后做任务时把环境改坏了，一键回到这个状态
- 注意：快照会额外占磁盘，不要频繁拍；拍之前先关机（关机状态最干净）

### 第三层：离线备份（可选，最保险）
- 把 `E:\VirtualBoxVMs` 整个文件夹复制到 D 盘或移动硬盘
- 或用 VirtualBox"导出虚拟电脑"导出为 .ova 文件（体积大，但可迁移）
- 防止宿主机磁盘损坏/误删导致环境全丢

## 三、不随虚拟机保存的东西（要单独记）
| 内容 | 在哪 | 说明 |
|---|---|---|
| VirtualBox 网络配置 | VirtualBox 全局设置 | host-only 网段 #2/#3（192.168.10.1 / 192.168.20.254）、NAT 网络 p1-wan（10.0.2.0/24） |
| 账号密码 | E:\实验账号密码.txt | 本地保存，**不要放进 Git 仓库** |
| 文档与截图 | GitHub 仓库 | 部署记录、复盘手册、报告、截图 |

## 四、随时复现任务的步骤
1. 开机顺序：`p1-pfsense` → 其他需要的机器（wazuh / client / web / waf / kali）
2. 按本文地址表访问对应服务
3. 若环境被改坏：VirtualBox 里选择该虚拟机 → 快照 → 恢复到 `p1-complete`
4. 若整个环境丢失：按 GitHub 仓库里的部署文档（docs/01-每周记录/）重建

## 五、与 P2 共存
- P2 使用**新克隆的虚拟机**（管理机 + 3 台被测机），**不修改 P1 的任何机器**
- 两组环境按需开机切换（不需要同时运行，内存也够）
- P2 的机器同样从 `ubuntu2404-template` 克隆，模板保持干净
