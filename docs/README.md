# docs 目录导航

本目录按用途分为 5 类，方便查阅和继续维护。

| 目录 | 放什么 | 主要文件 |
|---|---|---|
| **00-总览** | 项目全貌与规划 | 总路线图、P1-项目总结、P1-环境保存与恢复说明 |
| **01-每周记录** | 第 1-5 周的过程记录 | 各周部署/加固/整改/演练记录、防火墙策略说明 |
| **02-复盘与练习** | 复盘材料与练习体系 | P1-复盘与独立复现手册、P1-排错方法论与故障演练卡、闭卷复现记录、任务卡 |
| **03-学习资料** | 长期参考资料 | 网安实战项目学习手册(docx)、最小基础知识清单 |
| **04-求职准备** | 就业相关材料 | 岗位地图与适配度、秋招行动清单、简历项目描述模板、运维与网安面试八股 |

## 推荐阅读顺序
1. 想快速了解项目：`00-总览/P1-项目总结.md`
2. 想看做了什么：`01-每周记录/`（按周）
3. 想复习与练习：`02-复盘与练习/P1-复盘与独立复现手册.md`
4. 想查概念/命令：`03-学习资料/`
5. 准备找工作：`04-求职准备/`

## 其它目录
- `architecture/`：网络拓扑图
- `scripts/`：脚本与剧本
- `configs/`：配置文件片段
- `screenshots/`：实验截图
- `reports/`：安全事件报告
